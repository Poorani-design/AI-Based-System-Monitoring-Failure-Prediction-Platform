# AI-system-monitor
A full-stack web application that monitors system performance metrics and predicts potential failures using basic AI techniques.

📌 Overview

An AI-powered system monitoring platform that tracks CPU usage, memory consumption, and network traffic in real-time, and predicts potential system failures using intelligent data analysis.
This project demonstrates full-stack development, API design, and basic AI-based anomaly detection.

🎯 Features

      📊 Real-time CPU, memory, and traffic monitoring
      🤖 AI-based anomaly detection & prediction
      🔐 Secure authentication (JWT)
      📈 Interactive dashboard with charts
      📡 RESTful APIs (Node.js + Express)
      🗄️ MongoDB data storage
      
🧠 AI Prediction Logic

      Moving average / threshold-based detection
      Identifies abnormal spikes
      Predicts potential system overloads
🛠️ Tech Stack

      Layer	Technology
      Frontend	React, Axios
      Backend	Node.js, Express
      Database	MongoDB
      Auth	JWT
      Charts	Recharts / Chart.js
